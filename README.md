# Job Application Tracker (React Native)

A small cross-platform app to log and track your own job applications company, role,
status (Applied / Interview / Offer / Rejected), date, and notes. Data is saved locally
on device with AsyncStorage.

Why build this one specifically: it's a real, working app you're using yourself, it
shows RN + state management + local persistence in a portfolio friendly repo, and it
doubles as an actual tracker for your own search.
